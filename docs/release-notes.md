Windows 64 位桌面版，免装 Python。

v1.0.1 补充 MIT 许可证，运行包、源码包及桌面安装后的目录均保留许可证文件；新增可复现的性能测量脚本和基线报告。文件移动、哈希核对及日志刷盘策略保持不变。

下载 `FolderTidy-1.0.1-windows-x64.zip`，完整解压后双击 `安装到桌面.cmd`。安装会创建桌面“文件整理助手”图标，之后可直接从桌面打开。

支持整理预览、按类型归类、同名保留、失败继续处理，以及有文件核对保护的撤销。

`folder-tidy-1.0.1-source.zip` 和 GitHub 自动生成的 `Source code` 是源码包，供开发者使用。

适用 Windows 10 / 11 x64，本地 NTFS 文件夹。发布包附带 SHA-256 校验值。
