Folder Tidy · 文件整理助手 v1.0.1
适用：Windows 10 / Windows 11，64 位。
无需安装 Python，无需联网，无需管理员权限。

首次使用
1. 先把 ZIP 完整解压，不要在压缩包内直接运行。
2. 打开解压后的 FolderTidy 文件夹，双击“安装到桌面.cmd”。
3. 出现安装完成提示后，软件会打开；桌面上也会出现“文件整理助手”图标。
4. 以后双击桌面图标即可。安装后可以删除下载的 ZIP 和解压目录。

安装位置：当前用户的 %LOCALAPPDATA%\Programs\FolderTidy\versions。
首次安装会复制软件到此固定位置，创建指向该位置的桌面快捷方式。
重复安装会创建新版本目录并更新本软件的快捷方式，不覆盖无关快捷方式。
不会自动删除旧版软件。重新分发前请保留 THIRD-PARTY-NOTICES.txt。

免安装使用
也可以直接双击 FolderTidy.exe。请保持它和 _internal 文件夹在一起。
这种方式不会创建桌面快捷方式，需要保留解压后的软件文件夹。

整理文件
选择文件夹 → 预览整理 → 检查方案 → 开始整理。
文件按类型放进原目录中的 PDF、Images、Archives 等分类文件夹。
同名文件保留双方；无法访问的文件报告失败，继续处理其他文件。
只整理第一层，不进入已有子目录。当前需要支持硬链接的文件系统，例如本地 NTFS。

撤销整理
选择当时整理的文件夹 → 预览撤销 → 确认撤销。
新增文件不会被删除。原位置出现其他文件，或归类文件被修改时，会提示冲突并保留现场。
请保留整理目录中的 .folder-tidy 操作记录。

卸载
先关闭软件，再删除桌面“文件整理助手”快捷方式及安装位置下的 FolderTidy 文件夹。
卸载软件不会撤销已整理的文件；如需恢复，应先使用软件撤销。
